# Zenkai Quest

Dragon-Ball-Fan-Roguelite für den Browser (mobile-first): Idle-Kampf, Build-Entscheidungen, Meta-Progression.

- 3 Sagas (15/20/20 Etagen), Endlos-Modus, 10 Schwerkraft-Stufen, 6 Kämpfer, Gegner-Eigenschaften, Relikte.
- Reines HTML/CSS/JS, kein Build-Schritt. Spielstand liegt im `localStorage`.
- `data.js` Daten · `art.js` selbst gezeichnete SVG-Kämpfer/Hintergründe · `fx.js` Canvas-Effekte · `game.js` Logik/UI.
- Lokal testen: `npx http-server .` (oder `index.html` direkt öffnen).
- **Netlify:** Repo verbinden, Build command leer lassen, Publish directory `.` (steht schon in `netlify.toml`).
- Dragon Ball ist urheberrechtlich geschützt – für eine öffentliche Veröffentlichung eigene Namen/Grafiken verwenden.
